# v0.1 の仕様 — 見る・試す・書き出す

最初の公開版。作品として Web に出し、反応を見る（ADR-0003）。範囲は 2026-10-27 に利用者と決めた。

## 体験

1. **入口**: 見本の絵が3〜5枚あり、色だけで1日を巡っている。自動再生はしない。最初の画面で、再生の操作がはっきり分かる（ADR-0006）。
2. **自分の絵**: 画像を落とすと、16色の島と、その役割（空・灯り・天体・水・影・中間）を自動で推す。画像は端末の外に送らない。
3. **島を直す**: 島ごとに役割を付け替えられる。同じ色の空と海を、上下の線1本で分けられる（ADR-0004 の追記）。
4. **台本**: プリセットは「1日の光」「長い夕暮れ」「夜の灯り」の3つ。スライダーは「長さ」「夜の深さ」「灯りの強さ」の3つ。
5. **書き出し**: MP4 のループと、好きな時刻の静止画（PNG）。光過敏の判定（WCAG と ITU）に通ったものだけを書き出す。

入れないもの: 台本のタイムライン編集、アカウント、クラウド保存、共有の仕組み、決済、絵を描く機能。

## 受け入れの基準

| 領域 | 基準 | 確かめ方 |
|---|---|---|
| 色の正しさ | OKLab の基準値（`tools/visual-qa/probe-eval.mjs` の5色）が小数3桁で一致。色域変換は L と色相を保ち彩度を下げる | Vitest |
| 元の絵を壊さない | 台本の始まりと終わり（元のパレット）で、元の画像を再現する（PSNR ∞） | Vitest と画面の検査 |
| 重み | 非負・総和 1・パレット色で補間（ADR-0004） | Vitest |
| 光過敏 | 3つのプリセット × 見本の絵の全部 × スライダーの両端で、書き出した MP4 が WCAG と ITU の両方に合格 | `flash-check` |
| 動きを減らす設定 | `prefers-reduced-motion: reduce` で自走しない（5秒間の画素差 0） | `tools/visual-qa` |
| 速さ | 1920×1080 の描画が 60fps（実機の GPU）。前処理は 2MP の画像で 1 秒以内 | `tools/visual-qa` |
| 書き出し | 1080p・12 秒の MP4 が、ffprobe で正しい形式・長さ・フレーム数。ループの継ぎ目が隣のコマと同程度 | `ffprobe` と PSNR |
| 外枠の UI | 情報を色だけで伝えない。キーボードで全操作ができる。焦点が見える | メインの目視と画面の検査 |
| 見た目 | 3つのプリセットが、見本の絵のどれでも「カラーフィルタ」に見えない。夜が夜に、灯りが灯りに見える | メインの目視（8時点の一覧） |

## 段取り（ADR-0001 の体制）

| 段 | 中身 | adviser | 実行 |
|---|---|---|---|
| M1 骨組みと心臓部 | `app/` の骨組み、色の計算・パレットの抽出・Shepard の重み（Worker）、WebGL2 の合成、台本の再生（メインの v2 の台本を移す）、単体テスト | Codex（専用のワークツリー） | 切った易しい部分は dsh、難しい部分は Codex |
| M2 操作と書き出し | 画像の読み込み、役割の付け替え、上下の線での島の分割、プリセットとスライダー、書き出しと光過敏の判定、動きを減らす設定 | Codex | 同上 |
| M3 見た目と入口 | 外枠の UI の視覚設計（トークン・配置・状態）、見本の絵3〜5枚、3つのプリセットの台本の数値、入口の体験 | メイン（Claude） | 実装は Codex か dsh に振る。見た目の判断はメイン |
| M4 公開前の確認 | Firefox・Safari の確認、アクセシビリティの点検、低性能の環境での速さ、静的な配置 | メイン | dsh と Codex |

- M3 の設計（トークン、見本の絵、台本の数値）は、M1 と並行して始める。
- 各段の終わりに、メインが受け入れの基準で確かめてからコミットし、次の段へ進む。
