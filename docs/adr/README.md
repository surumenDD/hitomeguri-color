# ADR（設計判断の記録）

1つの判断を1つのファイルに書く。番号は増やすだけで、使い回さない。判断を変えるときは古い ADR を消さず、新しい ADR を書いて古いほうの状態を「置き換え済み（ADR-xxxx）」にする。

## 状態

- 提案 … 書いたが、根拠がそろっていないか、利用者の確認待ち
- 承認 … この判断で進める
- 置き換え済み … 新しい ADR に変わった
- 却下 … 検討したが採らなかった（理由を残すために消さない）

## 書式

```markdown
# ADR-xxxx: <題>

- 状態: 提案 | 承認 | 置き換え済み（ADR-yyyy） | 却下
- 日付: YYYY-MM-DD

## 文脈
何が問題で、何が分かっていて、何が制約か。根拠の原文があれば場所（~/research/<話題>/sources/<file>:行）を書く。

## 決定
何をするか。

## 理由
なぜそれか。

## 結果
良くなること、悪くなること、あとで見直す条件。

## 検討した他の案
採らなかった案と、採らなかった理由。
```
