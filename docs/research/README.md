# 調査

作るものを決める前に、4つの話題を imozuru で調べる。原文は `~/research/<話題>/` に置く（リポジトリには入れない）。各話題の入口は `digest.html`（解説）と `report.html`（抜き書き）。

| 話題 | 置き場 | 問い（短く） |
|---|---|---|
| 既存の有料プロダクト | `~/research/color-products-market/` | 色を操作・鑑賞するのが中心の有料品は何を売り、使い手は何に払い、何に不満か |
| 色彩科学・知覚 | `~/research/color-perception-science/` | 調和・好みの予測、知覚的に均等な色空間、絵の具の混色、同時対比 |
| 人間工学 | `~/research/color-ergonomics/` | 色を選ぶ UI、色覚の多様性、光過敏、目の疲れ、動きの不快感 |
| 作り手の技 | `~/research/generative-color-craft/` | 上手い作り手は色をどう選び、制約し、時間の中で動かすか |

ほかに、実装を任せるモデルの比較として次を行う。

- `docs/research/model-survey.md` … 公開情報によるモデルの比較
- `experiments/model-probe/` … 同じ課題を各モデルに解かせた結果

## 次の段取り

1. 4つの調査が止まったら、論点ごとに原文を読み、設計に効く知見を拾う
2. 知見をもとに案を複数出す（モデルを変えて発散させる）
3. 利用者と案を絞る
4. 決めたことを ADR にする（作るもの、プラットフォーム、色の計算、アクセシビリティの基準、品質の基準）
