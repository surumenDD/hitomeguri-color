# 人物の重ね（試作）の設計

ADR-0009 の試作の、見た目・操作・式・受け入れの基準。メイン（Claude）が持つ視覚の設計で、実装はこの文書に合わせる。採用は利用者が試作を見て決める。それまで main に合流させない。

## 考え方

- 背景は今までどおり、島と台本で色がめぐる。人物は島に分けず、**その時刻の光を受けて、なじむだけ**にする。
- 人物は主役ではあるが、場面の外から貼った物に見えてはいけない。夜には背景と一緒に暗くなり、空の色を少し受ける。ただし、背景ほどは沈めず、顔の線が読める明るさを残す。
- 台本の始まりと終わりでは、人物は元の絵と1画素も違わない（ADR-0004 と同じ約束）。

## なじませ方（式）

コマごとに、台本から次の2つを求める（CPU で1回）。

- **空の基準色** `S(t)`: 帯の上段の色（上空。面積が最大の「空」の島）と、下段の色（地平。最も暖かい「空」か「水」の島）の、OKLab での平均。時刻 t の色で、`S0 = S(0)` は元の色。「空」の島が無い絵では、人物を変えない（k = 1、ずらし 0）。
  - 2026-10-27 改める（メインが試作の素材で式を試した結果）: 初めは上空の色だけにしていた。夕方の絵では上空がすでに藍色なので、夜になっても色の変化が小さく、人物が暖かい灰色のまま暗い背景から浮いた。人に当たる光の色を大きく変えるのは地平（夕方の橙 → 夜の藍）なので、上空と平均する。
- **明るさの比** `k(t) = clamp(S_L(t) / S0_L, 0.05, 1.25)`。

人物の各画素（OKLab の `L, a, b`）に、目盛り「夜のなじみ」`f`（0〜1、標準 0.8。2026-10-27 に 0.65 から改める。0.65 では夜の人物が明るすぎて浮いた）を使って次を当てる（シェーダーで）。

```
L' = L × (1 + f × (k − 1))
L' = clamp(L', 0.35 × L, 1)            … 人物を消さない。白を超えない
c  = 1 − 0.35 × f × (1 − min(k, 1))    … 暗いほど彩度を少し落とす
(a', b') = (a, b) × c + 0.5 × f × (S_ab(t) − S0_ab)   … 空の色の変化の半分を受ける
```

- t = 0 と終わりでは `k = 1`、`S = S0` なので、人物は元のまま。
- `f = 0` では、どの時刻でも人物は元のまま。
- 例: 深夜に基準色の L が 0.55 → 0.18（k = 0.33）なら、f = 0.8 で人物の明るさは 0.46 倍になる。白い顔（L 0.95）は 0.44 で、暗い背景に溶け込みながら顔の線は読める（試作の素材の海辺で確かめた）。地平の橙から藍への変化の 4 割（0.5 × 0.8）を受けて、人物は青みを帯びる。夜明けには赤みが差す。
- 昼に空が元より明るくなると（k > 1）、人物も少し明るくなる（標準の f = 0.8 で最大 1.20 倍、f = 1 で 1.25 倍）。

色域の外に出たら、今と同じ `gamutMap`（L と色相を保ち、彩度を下げる）で戻す。合成は線形の光で行う: `out = bg × (1 − α) + fg' × α`（α は人物のアルファ、ストレートの値）。

島を選んだときと分割中の沈め（L × 0.6、C × 0.25）は、人物にも同じように当てる。人物は島ではないので、強調する側に来ることはない。プレビューだけで、書き出しには当てない。

## 置き方

- **大きさ**: 人物の高さを、絵の高さに対する割合で持つ（20〜120%、標準 70%）。幅は縦横比を保つ。
- **位置**: 人物の下端の中心を、絵の座標（左上 0,0、右下 1,1）で持つ。標準は `x = 0.68`、`y = 1.0`（絵の下端にそろえ、右寄り3分の2の線の近く）。絵からはみ出してよい（はみ出た分は描かない）。
- マウスやタッチでは、人物をドラッグして動かす。
- キーボードでは、人物の外接矩形に重ねた、見えない `button` で動かす。
  - `aria-label` は「人物の位置。矢印キーで動かします」。
  - 矢印キーで 1%、Shift と一緒で 10% 動く。
  - 焦点が来たら、外接矩形に白い 1px の点線を出す（焦点の輪と同じ白）。
- 人物の画像は長い辺を 2048px までに縮めてから使う。
- **位置の範囲**（2026-10-27 追記、adviser の質問への回答）: 下端の中心の x は 0〜1、y は 0.2〜（1 ＋ 大きさ × 0.5）。足元から人物の高さの半分までは、絵の下へはみ出してよい。範囲に上下限を設けないと、ドラッグで人物を絵の外へ放り出して見失うため。
- **背景を替えたとき**（同上）: 人物の画像、大きさ、位置、夜のなじみは保つ。同じ人物をいろいろな背景に置くことが、この機能の狙いのため。
- **空の元の明るさが 0 のとき**（同上）: 比だけ `k = 1` にし、色のずらしは式どおりに求める。

## パネル

「色の島」の節の下に、節「人物」を足す。見出しの書き方は「色の島」と同じ。

- **人物が無いとき**:
  - 説明（14/20px、`#9B9B9B`）: 「背景が透けた PNG の人物を重ねられます。人物は色の島に入れず、時刻になじませます。」
  - 二次ボタン「人物の絵を重ねる」。受け付けるのは `image/png,image/webp`。
- **人物があるとき**:
  - 1行目: 小さな見本（高さ 48px、`#272727` の台、角丸 8px）、ファイル名（拡張子を外す。今の絵の名前と同じ作り）、文字だけのボタン「外す」（`#9B9B9B`）。
  - 目盛り「大きさ」: 20〜120% の直線。標準の 70% がちょうど中央。出力欄は「70%」。
  - 目盛り「夜のなじみ」: 0〜1 の折れ線。左半分を 0→0.8、右半分を 0.8→1 に割り当て、標準を中央に置く（ほかの目盛りと同じ考え）。出力欄の言葉は「なし・弱め・ふつう・強め・同じ」（0、0〜0.8、0.8、0.8〜1、1）。
- **透過の無い画像を選んだとき**: 「この画像には透けた部分がありません。背景が透けた PNG を選んでください。」を、今のエラーの見た目（Notice）で出し、人物は重ねない。判定は、アルファが 250 未満の画素が 1% 未満なら「透過なし」とする。
- 読み込み中は、今の絵の読み込みと同じく、人物の節の操作も `disabled` にする。

書き出しの横の文言と、画像を外へ送らない約束は変えない。人物の画像も端末の外へ送らない。

## 言葉

人物、人物の絵を重ねる、外す、大きさ、夜のなじみ。「レイヤー」「前景」「アルファ」は画面に出さない（使い手の言葉ではない）。

| 領域 | 基準 | 確かめ方 |

| 元に戻る | 人物つきの描画が、台本の始まりと終わりで「元の背景に、元の人物を線形の光でアルファ合成したもの」と一致する（8ビットで差 1 以下） | Vitest と画面の検査 |
| なじみ 0 | どの時刻でも、人物の画素が元のまま | Vitest |
| 明るさの範囲 | 人物の L' が `0.35 × L` 未満にならず、1 を超えない | Vitest |
| 点滅 | 3つの台本 × 人物つき（試作の素材）で、書き出した MP4 が WCAG と ITU の両方に合格 | `flash-check` |
| 人物なし | 人物が無いときの動作と見た目が今と同じ（既存の検査が全部通る） | `npm run check` ほか既存の検査 |
| 操作 | 重ねる、外す、大きさ、夜のなじみ、位置が、キーボードだけで使える。axe の違反 0。焦点が見える | 3ブラウザの検査 |
