# 色の台本の設計（アートディレクション）

メイン（Claude）が持つ、視覚的センスの要る設計の記録（ADR-0001）。数値の正本は `experiments/role-script-spike/script.js`。M2 では、この版の数値をそのまま `app/` に移す。

## 原則

1. **元の絵から始まり、元の絵に戻る**。台本の最初と最後の状態は、元のパレットそのもの。元の絵は「夕方」として描かれている前提（見本の絵もすべて夕方）。
2. **暖色と寒色の対比を、どの時点でも保つ**。空と水の各色について、元の色の暖かさ（`warmth()`）を測る。暖色の側（地平・映り込み）と寒色の側（上空）に、時点ごとに別の目標を与えて混ぜる。画面全体を1つの色相に寄せると、カラーフィルタに見える（v1 の失敗）。
3. **役割ごとに時計をずらす**。空が先に変わり、水は遅れて空を追い、灯りは少し先にともる。ずれには sin² の包絡を掛け、ループの継ぎ目では 0 にする。
4. **灯りは灯りらしく**。残照でともり、夜に最も明るく、夜明けに弱まり、朝には周りになじむ。灯りは自分の色相を保ったまま琥珀へ 35% だけ寄せる（朱の提灯は朱のまま）。赤から橙の灯りは明るさの床を低めにする（明るすぎる赤は桃色に転ぶ）。
5. **夜は深い藍**。彩度 0.03 前後の夜は灰色のスレートに見える。深夜と夜の終わりは彩度 0.05 前後、色相 258〜272。
6. **天体（月）は夜に青白く、朝の空に溶ける**。

## 状態とプリセット

状態は8つ: `original`（元の絵）、`afterglow`（残照）、`blueHour`（ブルーアワー）、`midnight`（深夜）、`lateNight`（夜の終わり）、`twilight`（薄明）、`sunrise`（日の出）、`morning`（朝）。プリセットは、状態を時刻の割合の列で並べたもの。

| プリセット | 長さ | 並び | nightDepth | glow |
|---|---|---|---|---|
| 1日の光 | 24 秒 | original → afterglow → blueHour → midnight → lateNight → twilight → sunrise → morning → original | 1 | 1 |
| 長い夕暮れ | 20 秒 | original → afterglow → blueHour → afterglow → original（マジックアワーが呼吸する） | 0.85 | 1 |
| 夜の灯り | 32 秒 | original → afterglow → blueHour → midnight → lateNight → midnight → blueHour → original | 1.1 | 1.25 |

スライダー（v0.1）: 「長さ」は durationSec、「夜の深さ」は nightDepth（夜の重みの大きい状態ほど暗くする量を倍率で変える）、「灯りの強さ」は glow。

## 版の履歴

| 版 | 変えたこと | 理由（メインの目視） |
|---|---|---|
| v1（Codex） | 役割ごとの台本を初めて作った | 夜は夜に、灯りは琥珀に見えた。始まりが元の絵から離れ、夜明けと朝が一様な色のフィルタに見えた |
| v2 | 原則 1・2・4（灯りが消える）・6 | 夜明けが「金の地平・青い上空・菫の影」になり、フィルタに見えなくなった |
| v3 | 原則 5（深夜を藍に） | 深夜が灰色のスレートに見えた |
| v4 | 原則 4 の後半（灯りの色相を保つ、赤の床を下げる） | 運河の朱の提灯が、夜に淡い黄色になり、次に鮭色になった |

## 見本の絵の役割の手付け

入口の見本の絵は、役割を手で付けて絵とセットで持つ（`assets/hero/roles.json`）。読み込みのとき、抽出したパレットの各色を、最も近い手付けの色（OKLab の距離 0.04 以内）に合わせる。番号ではなく色で持つのは、パレットの抽出の実装が変わっても合わせられるようにするため。

色だけでは分けられないもの（オアシスのテントの布と砂丘、テントの壁と岸の砂）がある。テントの壁の色を「灯り」にしたら、同じ色の岸まで夜に光った。これは位置で分ける島（`regions` の矩形）で扱う。M2 の「上下の線で分ける」機能を、矩形にも一般化して作る。
