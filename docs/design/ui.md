# 外枠の UI の設計（アートディレクション）

メイン（Claude）が持つ、視覚的センスの要る設計の記録（ADR-0001）。見本は `experiments/ui-mock/`（`index.html` と、画面写真 `mock-desktop.jpg`・`mock-mobile.jpg`）。M2・M3 の実装は、この見本の見た目に合わせる。

## 考え方

- **主役は絵**。外枠は暗い展示室のように黙る。色が正しく見えることを優先する（Turrell の、空を切り取る部屋の考え）。
- **大胆さは1か所だけ**: **カラースクリプトの帯**。絵の下に、いまの絵と台本の1周を1本の帯で置き、それ自体を時刻のスライダーにする（Pixar のカラースクリプトを操作できる部品にしたもの）。1日の全体が一目で分かる。
- **差し色は固定しない**。差し色は、いまの時刻の絵の地平の色から取る（帯の下段の色）。使うのは時刻の名前だけ。夜の地平の色は暗くて読めないので、文字に使うときは明るさだけを持ち上げる（下の「時刻の名前の色」）。焦点の輪は見やすさのため白で固定する。
- パネルに板を敷かない。部屋そのものをパネルにして、絵だけを物として置く。

## カラースクリプトの帯

- 上下2段。上段は、面積が最大の「空」の色（上空）。下段は、元の絵で最も暖かい「空」か「水」の色（地平の帯）。各段とも、台本の1周を 64 点ほどで標本にして、横のグラデーションにする（計算は `experiments/ui-mock/strip.mjs`）。
- 面積で重み付けした平均色は使わない。暗い影に引っ張られて、濁った灰青になる（試して確かめた）。
- 帯は `role="slider"`。矢印キーで時刻を動かせる。`aria-valuetext` は「残照、3.0 秒」のように、時刻の名前と秒を読む。
- 再生の位置は白い縦線。時刻の名前（夕方・残照・青の時間・深夜・夜明け前・薄明・日の出・朝）を帯の右に、差し色で出す。

## 書体

**Zen Kaku Gothic New**（OFL、`@fontsource/zen-kaku-gothic-new` で手元に置く。CDN は使わない）を1つだけ使う。400・500・700。

`landing-page-design` B1 が挙げる書体（Geist など）には和文が無い。日本語の UI なので、和文と欧文を1つの家族で持つこの書体にした。ADR-0002 の「規則から外れたら書く」に従い、ここに記録する。「1サイトに書体は1つ」「極太（900）を使わない」「斜体を使わない」は守る。

## 配置

```
┌ ひとめぐり 絵の色が、1日をひとめぐりする        [見本×5] [自分の絵を開く] ┐
│ ┌─────────────────────────────┐   台本  [1日の光|長い夕暮れ|夜の灯り] │
│ │                             │   長さ ──●──   夜の深さ ──●──      │
│ │            絵               │   灯りの強さ ──●──                  │
│ │                             │   色の島 [■空][■影][■灯り]…        │
│ └─────────────────────────────┘   [動画を書き出す]                  │
│ (▶) ▓▓▓▓▓カラースクリプトの帯▓▓▓▓▓  残照 3.0/24秒  [この瞬間を画像で保存] │
└──────────────────────────────────────────────────────────────────────┘
```

- 横長: 絵と帯が左、操作が右（幅 320px）。
- 縦長（960px 以下）: 縦に積む。帯は全幅、その下に再生と時刻。

## 状態の見た目（2026-10-27 追記、M2 の adviser の質問への回答）

### 書き出しの進み具合と中止

- 置き場所: パネルの書き出しの区画の中。「動画を書き出す」ボタンが、その場で同じ大きさ（高さ・角丸 8px）の進み具合の帯に変わる。新しい部品は足さない。
- 帯の中身: 台の色は `#272727`。満ちる部分は、**その絵のカラースクリプトの帯と同じグラデーション**（下段、地平の色）を、左から進み具合の分だけ見せる。帯が「刷り上がっていく」ように見せ、署名の部品をもう一度使う。
- 文字: 帯の下に1行、14/20px、`#ECECEC`。段階は順番がある2段なので番号を付けてよい: 「1/2 点滅を確かめています 42%」→「2/2 動画を作っています 73%」。数字は等幅の数字（tabular-nums）。
- 中止: 「この瞬間を画像で保存」ボタンの場所が「中止」（同じ見た目の二次ボタン）に変わる。書き出しを始めたら、焦点を「中止」へ移す。書き出し中は、パネルのほかの操作を無効にする（`aria-disabled`）。絵の再生は止める。
- 終わったら: 帯を満ちたまま 1.5 秒見せてからボタンに戻し、注記の行に「保存しました（ひとめぐり-運河の街-24秒.mp4、6.6MB）」と残す。中止したら「中止しました」。
- 読み上げ: 帯は `role="progressbar"`、文の行は `aria-live="polite"`。
- 動きを減らす設定では、満ちる動きの遷移を付けない（値だけ更新する）。

### エラーと読み込み中

- 赤い色は足さない。**アイコンと文の組**で示す（色だけに頼らない、ADR-0006）。アイコンは Phosphor（MIT）の warning-circle、16px、文字と同じ色。
- 形: `#272727` の面、角丸 8px、内側の余白 12px、アイコンと文の間 8px、14/20px。`window.alert` は使わない。起きた場所のすぐそばに出す。
- 文は「何が失敗し、どうすればよいか」を具体的に書く。謝らない。
  - 読み込みの失敗（画像の下、帯の上の位置に出す）: 「この画像は開けませんでした。PNG・JPEG・WebP の画像を選んでください。」 このとき、それまでの絵はそのまま残す。
  - 大きな絵（長辺が 2048 px を超える）は断らず、長辺 2048 px に縮めて開く。その絵を開いている間、絵の下の注記に「長辺 2048 px に縮めて開きました（元の大きさは 3000×3000）。」と出す。MP4 はもともと長辺 1920 px までで書き出すので変わらず、PNG はこの大きさで保存する（2026-10-28 改める。それまでは長辺 4096 px を超える絵を断り、それ以下は縮めずに解析していた。3000×3000 の絵では、開くのに 14 秒、スライダー1目盛りに 11〜24 秒かかった）。
  - 安全の判定で書き出せない（書き出しの区画、注記の行の代わり）: 「この設定では、光の変化が速すぎて点滅の基準を超えます（1秒に4回、画面の32%）。長さを伸ばすか、夜の深さを浅くしてください。」 設定が変わるまで書き出しのボタンは無効。
  - 編集中の見積もり（スライダーの真下に、控えめな文字 `#9B9B9B` とアイコンで）: 「これより短くすると、点滅の基準を超えます」。スライダーは安全な端で止める。
  - 書き出しに非対応（書き出しの区画）: 「このブラウザでは動画を書き出せません。Chrome・Edge・Firefox（デスクトップ）・Safari 16.4 以降で開いてください。静止画の保存はこのまま使えます。」
- 読み込み中（B9）: 回る印は使わない。絵の場所に、絵と同じ縦横比の `#1F1F1F` の面を置き、帯の場所にも同じ面を置く（形をそろえた骨組み）。2.4 秒周期のごく弱い明滅（明るさの差 3% 以内）。動きを減らす設定では静止。文の行に「色を調べています」。

### 色の島の一覧（役割ごとの行）

- 島は 16 前後（位置で分けると 19 以上）あるので、札を格子に並べず、**役割ごとの行**にまとめる。「すべて表示」で畳む形にはしない（すべての島が一目で見えることを優先する）。
- 1行 = 左に役割の名前（12/16px、`#9B9B9B`、幅 40px。上に 2px の余白を足して、高さ 20px の色見本の1行目の中央に合わせる。行の高さだけを変えるのは `landing-page-design` B1 に反するので、しない）＋ 右にその役割に属する島の色見本。色見本は 28×20px、角丸 4px、間 4px、面積の大きい順に並べ、収まらなければ折り返す。
- 行の順は 空・水・灯り・天体・影・中間。島が1つも無い役割の行は出さない。
- 色見本は `button`。`aria-label` は「空、面積 37%」、位置で分けた島は「空（上）、面積 21%」。選んだ色見本は `#ECECEC` の 2px の輪（2px 離す）。hover は 1px の `#9B9B9B` の輪。
- 役割を付け替えると、色見本がその役割の行へ移る。この道具の中心の考え（色を役割に分けて動かす）が、一覧そのものに見えるようにするため。

### スライダーの目盛り

- 3本とも、標準の値をつまみの中央に置く。スライダーごとに標準の位置がずれると、いまが標準かを目で読めなくなるため。
  - 長さ（12〜48 秒）は対数の目盛り。標準の 24 秒がちょうど中央に来る（長さは倍・半分で感じる量なので、対数が感覚にも合う）。
  - 夜の深さ（0〜2）は直線。標準の 1 が中央。
  - 灯りの強さ（0〜1.5）は折れ線。左半分を 0→1、右半分を 1→1.5 に割り当て、標準の 1 を中央に置く。
- 出力欄には、長さは秒、ほかの2本は目盛りの言葉（浅い・ふつう・深い、なし・ふつう・強い）を、最も近い言葉で出す。
- 点滅と明るさの検査の間も、スライダーは動かせる（2026-10-28 追記）。つまみと出力欄は入力にすぐ従い、絵には検査を通った値だけを使う。検査は1つずつ走らせ、走っている間に来た入力は最後の値だけを次に検査する。最後の値が通らなければ、通る端を探してつまみをそこへ移す（上の「スライダーは安全な端で止める」）。2本を続けて動かしたら、動かし始めた順に1本ずつ確定する。人物の「大きさ」「光のなじみ」も、検査の間に止めない。それまでは検査の間スライダーを無効にしていたので、ドラッグが途中で切れ、つまみが前の位置に戻って見えた。

### 島を選んだ後

- 島の札を押すと選ぶ（`aria-pressed`）。絵の上では、選んだ島の場所を残し、ほかを沈める。沈め方は **OKLab の L を 0.6 倍、彩度（C）を 0.25 倍**。選んだ島だけが色を保って浮き上がる。もう一度押すと外れる。
  - 2026-10-27 の改訂: 初めは「明るさ 35% に落とす」と書き、実装は線形の光の量を 0.35 倍にした。これは目に見える明るさでは約 62% で、夕暮れの暗い絵では選んだ島が浮き上がらなかった（メインが縮小した写真の目視で「暗くならない」と見誤るほど弱かった）。色の道具なので、強調は明るさより彩度で行う。
- 島の一覧の真下に、選んだ島の行が開く（板は敷かない）。中身:
  - 「役割」: ネイティブの `select`（操作の面 `#272727`、角丸 8px）。選べるのは 空・水・灯り・天体・影・中間。自動の推定と違うときだけ、横に「自動に戻す」（文字だけのボタン、`#9B9B9B`）。
  - 「上下の線で分ける」: 二次ボタン。
- 分ける操作:
  - 押すと、絵の上に横線が1本出る。初めの位置は、その島の重心の高さ。線は幅いっぱいの 1px の白（不透明度 70%）、右端に直径 16px の白い丸のつまみ。つまみは `role="slider"`（縦）で、上下の矢印キーで 1%、Shift と一緒で 10% 動く。`aria-valuetext` は「上から 52%」。
  - 線の上下で、いま動かしている側の反対を暗くして、どこが分かれるかを見せる。沈め方は、島を選んだときと同じ（OKLab の L を 0.6 倍、彩度を 0.25 倍。沈める表現の意味を1つに保つ）。
  - 線の左端の上と下に、小さな文字（12/16px、`#ECECEC`）で「上: 空」「下: 水」と出す。文字の下に、部屋の色を 72% で敷いた小さな札（余白 2px 6px、角丸 4px）を置き、線から 6px 離す（2026-10-27 改める、M4）。文字の影だけでは、昼の明るい空の上で読めるとは言えないため。札があれば、真っ白の上でも 5.9:1 以上になる。
  - 島の行には「上の役割」「下の役割」の2つの `select` と、「分ける」（主のボタン）・「やめる」（二次）を出す。
  - 分けたら、島の一覧で1つの札が2つになる（「空（上）」「水（下）」）。どちらにも「分割を戻す」を付ける。

## 時刻の名前の色（2026-10-27 追記、M4）

- 問題: 時刻の名前（`.when b`）を地平の色そのままで書くと、夜に読めない。運河の深夜は `#1f2b44` で、部屋の色 `#181818` とのコントラストが 1.25:1（axe で検出）。
- 規則: 地平の色の **OKLab の色相と彩度を保ち、L だけを 0.005 刻みで上げて**、部屋の色とのコントラスト（WCAG 2.x の相対輝度の比）が **4.5:1 以上になった最初の値**を使う。
  - L を上げて sRGB の外へ出たら、`gamutMap`（L と色相を保って彩度を下げる）で戻す。
  - 判定は、8ビットに丸めた16進の色で行う（丸めで 4.5 を割らないように）。
  - L は上げるだけで、下げない。もともと 4.5:1 以上の色（昼と夕方の地平）は、そのまま使う。
- 範囲: 時刻の名前の文字だけ。カラースクリプトの帯と、書き出しの進み具合の帯は図なので、地平の色をそのまま使う（絵の色の記録なので変えない）。
- 結果の見本（運河、1日の光）: 深夜 `#1f2b44` → `#72819e`（4.52:1）、夕方の終わり `#6b486f` → `#9a749e`（4.54:1）、夜明け前 `#7e3636` → `#ba6b69`（4.56:1）、夕方 `#f27a2f` は変えない（6.43:1）。夜の名前は、落ち着いた青灰と薄紫になる。地平の色の性格は残り、灰色に逃げない。
- 実装: `app/src/color/` に純粋な関数を1つ置く（例 `legibleOn(hex, background = '#181818', ratio = 4.5)`）。差し色（`--accent`）にはこの関数を通した色を入れる。単体テストは、上の見本の4色の入力と、出力のコントラストが 4.5 以上で 4.7 未満（持ち上げすぎない）か、元の色のままであること。

## 言葉

- 製品名は「ひとめぐり」で進める（2026-10-27 に利用者が了承。良い案が出れば変える可能性がある）。副題は「絵の色が、1日をひとめぐりする」。名前を変えるときに差し替えが小さく済むよう、名前は1か所の定数から読む。
- 操作の名前は、何が起きるかをそのまま書く: 「自分の絵を開く」「再生」「動画を書き出す」「この瞬間を画像で保存」。
- 色の島には役割の名前だけを出す（色コードは出さない。使い手には要らない）。
- 書き出しの横に「点滅の基準に通った動画だけを書き出します。画像は外へ送りません。」と書く（ADR-0003・0006 の約束を、使い手に見える形で言う）。
