# 外枠の UI の設計（アートディレクション）

メイン（Claude）が持つ、視覚的センスの要る設計の記録（ADR-0001）。見本は `experiments/ui-mock/`（`index.html` と、画面写真 `mock-desktop.jpg`・`mock-mobile.jpg`）。M2・M3 の実装は、この見本の見た目に合わせる。

## 考え方

- **主役は絵**。外枠は暗い展示室のように黙る。色が正しく見えることを優先する（Turrell の、空を切り取る部屋の考え）。
- **大胆さは1か所だけ**: **カラースクリプトの帯**。絵の下に、いまの絵と台本の1周を1本の帯で置き、それ自体を時刻のスライダーにする（Pixar のカラースクリプトを操作できる部品にしたもの）。1日の全体が一目で分かる。
- **差し色は固定しない**。差し色は、いまの時刻の絵の地平の色から取る（帯の下段の色）。使うのは時刻の名前だけ。焦点の輪は見やすさのため白で固定する。
- パネルに板を敷かない。部屋そのものをパネルにして、絵だけを物として置く。

## カラースクリプトの帯

- 上下2段。上段は、面積が最大の「空」の色（上空）。下段は、元の絵で最も暖かい「空」か「水」の色（地平の帯）。各段とも、台本の1周を 64 点ほどで標本にして、横のグラデーションにする（計算は `experiments/ui-mock/strip.mjs`）。
- 面積で重み付けした平均色は使わない。暗い影に引っ張られて、濁った灰青になる（試して確かめた）。
- 帯は `role="slider"`。矢印キーで時刻を動かせる。`aria-valuetext` は「残照、3.0 秒」のように、時刻の名前と秒を読む。
- 再生の位置は白い縦線。時刻の名前（夕方・残照・青の時間・深夜・夜明け前・薄明・日の出・朝）を帯の右に、差し色で出す。

## トークン

| 種類 | 値 |
|---|---|
| 部屋（背景） | `#181818` |
| 操作の面 | `#272727`、hover は `#313131` |
| 文字 | `#ECECEC`、控えめな文字は `#9B9B9B` |
| 焦点の輪 | 白 2px、2px 離す |
| 余白 | `landing-page-design` B2 の段（2, 4, 8, 12, 16, 24, 32, 40, 48 px） |
| 文字の大きさ | Tailwind の段（12/16、14/20、16/24、18/28 px） |
| 角丸 | 操作は 8px、入れ子は外 − 隙間（B3）、丸ボタンは全円 |

暗い面の色は `landing-page-design` B4 の一覧から選んだ。

## 書体

**Zen Kaku Gothic New**（OFL、`@fontsource/zen-kaku-gothic-new` で手元に置く。CDN は使わない）を1つだけ使う。400・500・700。

`landing-page-design` B1 が挙げる書体（Geist など）には和文が無い。日本語の UI なので、和文と欧文を1つの家族で持つこの書体にした。ADR-0002 の「規則から外れたら書く」に従い、ここに記録する。「1サイトに書体は1つ」「極太（900）を使わない」「斜体を使わない」は守る。

## 配置

```
┌ ひとめぐり 絵の色が、1日をひとめぐりする        [見本×5] [自分の絵を開く] ┐
│ ┌─────────────────────────────┐   台本  [1日の光|長い夕暮れ|夜の灯り] │
│ │                             │   長さ ──●──   夜の深さ ──●──      │
│ │            絵               │   灯りの強さ ──●──                  │
│ │                             │   色の島 [■空][■影][■灯り]…        │
│ └─────────────────────────────┘   [動画を書き出す]                  │
│ (▶) ▓▓▓▓▓カラースクリプトの帯▓▓▓▓▓  残照 3.0/24秒  [この瞬間を画像で保存] │
└──────────────────────────────────────────────────────────────────────┘
```

- 横長: 絵と帯が左、操作が右（幅 320px）。
- 縦長（960px 以下）: 縦に積む。帯は全幅、その下に再生と時刻。

## 言葉

- 製品名は仮に「ひとめぐり」。副題は「絵の色が、1日をひとめぐりする」。本決まりの前に利用者と相談する。
- 操作の名前は、何が起きるかをそのまま書く: 「自分の絵を開く」「再生」「動画を書き出す」「この瞬間を画像で保存」。
- 色の島には役割の名前だけを出す（色コードは出さない。使い手には要らない）。
- 書き出しの横に「点滅の基準に通った動画だけを書き出します。画像は外へ送りません。」と書く（ADR-0003・0006 の約束を、使い手に見える形で言う）。
