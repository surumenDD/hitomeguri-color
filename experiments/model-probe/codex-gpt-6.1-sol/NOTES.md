# Chromatic Field — 実装と検証

## 意図と構成
- 色を見て過ごす画面。広い色面をゆるく折り、入力した顔料の余韻を残す。
- WebGL2 の全画面三角形を採用。ブラウザの sRGB 合成を避け、画素ごとの OKLab 混合・色域補正を GPU で完結できるため。
- 外部依存・通信・フォント取得・ビルドは不要。操作はドラッグ、Space（色の再生成）、S（作品部分だけを PNG 保存）。
- 調和は分裂補色。基準色相 h の近傍 −22°/12°/35° と反対側 164°/194° に5色を配置し、明度と彩度に強弱をつける。

## 要件への対応
- R1: パレット・再生成時の補間・画面の混合・入力色の統合は OKLab / OKLCH。sRGB は入出力とスウォッチ表示のみ。
- R2: L と h を固定して C を二分探索で減らす。CPU は26回、GPU は a,b の同倍率縮小を16回。RGB のチャンネル切り詰めはしない。
- R3: 起動時に5色を生成。Space で再生成し、通常時は2.4秒かけて OKLab で移行する。調和のコメントをコード内に記載。
- R4: 5つの楕円状の重みと座標のうねりで場を描く。自走の周期は64・80・96秒。
- R5: 押すたびに5色を順番に使用。入力色を OKLab で混ぜ、半径を広げ、10秒以内に減衰させる。
- R5 補足: 描画核は最大32点。超過時は空間・時間・色が近い点を重み付きで統合する近似で、古い点の即時切り捨てを避ける。
- R6: S またはボタンで現在の描画を PNG 保存。保存直前に再描画し、未保持のフレームバッファを空画像として保存するのを防ぐ。
- R7: reduced-motion では自走・待機中の描画を止める。入力時だけ論理時刻を少し進めて色を更新する。設定変更にも追従。
- R8: 描画バッファを約207万画素以下に制限。1920×1080 はそのまま描画する。
- R9: ?selftest では canvas を作動させず、指定結果の JSON を pre と console.log に出す。
- R10: 自走を低速に限定。色の再生成も滑らかに移行し、キーリピートを無視。ディザは固定の OKLab 明度ノイズ。
- 既知の未達: なし。WebGL2 非対応環境では説明を表示する。実際の流体計算ではなく拡散核による近似。

## 自分で確認したこと
- Playwright の Chromium / ANGLE / NVIDIA GeForce RTX 5070 Ti でローカル HTTP 配信を開いた。WebGL2 が動作し GL エラーは0。
- selftest の pre を JSON 解析し、console.log と一致する値を確認。5色の OKLab 基準値からの誤差は最大0.0000463。
- 色域外の例は #00be58 / C=0.19277801、色域内の例は #7d5952 / C=0.05。未量子化値の逆変換で L 誤差 <4e−9、h 誤差 <0.00002°。
- 起動直後・約40秒後・ドラッグ後を撮影し、view_image で目視確認。5回のクリックで色の順番が一巡することも確認。
- 1920×1080 の180フレームを計測。初回は平均16.67ms / 95百分位16.80ms、統合処理追加後の32点入力時は17.13ms / 22.30ms（約58fps、GPU 単体の処理時間ではない）。
- Space でパレットが変わり、S で PNG がダウンロードできた。saved-field.png を view_image で開き、作品が入り操作表示が入らないことを確認。
- reduced-motion の待機2.2秒で時刻・描画回数・PNG スクリーンショットが完全一致。クリック後だけ描画回数が増え画像が変わった。
- 390×844 でも画面を表示し、横へのはみ出しがないことを確認。実機のタッチ入力は未確認。
- 最終版で長いドラッグ後の32点維持・約10秒後の0点への減衰・JavaScript エラーなしを確認。証跡: after-drag-final.png / spreading-final.png。
- その他の証跡: initial.png / after-motion.png / after-drag.png / saved-field.png / reduced-motion.png / mobile.png。
- 未確認: 他 GPU・Firefox・Safari・スマートフォン実機、OS からのファイル直接起動。検証ブラウザは file: URL を遮断するため HTTP を使用した。
- 時間があれば: 長い筆跡の統合精度、広色域表示、低性能 GPU での解像度調整を検証する。
