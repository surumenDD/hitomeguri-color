# 固定の重みの比較

作成日: 2026-10-27。読む人: ADR-0004 の重みと島の扱いを決める設計者・実装者。これは製品コードではなく、4枚の入力で候補を比べる試作である。

## 判断

**次の実装の基礎には、非負で補間条件を持つ Shepard を勧める。ただし、今回の結果だけで既定を確定しない。** 最近傍より境界の急変を減らし、Gaussian や今回の補間 RBF より実画像への到達が強い。元のパレットでの完全再現と、パレット点での補間も両立する。一方、大きな単色編集では細かな色むらが残り、「斑点が出ない」を4枚で満たした候補はなかった。

試験bのShepardの到達率は4枚で82.29〜91.73%、Gaussianは35.15〜52.28%、補間RBFは51.73〜60.51%だった。Shepardの斑点指標は最近傍から約25〜37%下がった。平らな色面では、到達91.73%に対して斑点48.583×10⁻³で、Gaussianの到達35.82%・斑点11.483×10⁻³より色の移動が強い。小さい斑点指標だけでGaussianを選ぶと、編集そのものの弱まりを見落とす。

空間平滑は高周波の数値を下げるが、平らな色面では細かな粒を大きな雲状のむらに変えた。既定には勧めない。色だけで空と海を分けることもできないので、**色の補間重みと、使い手が固定する島の分割を別の決定にする**のがよい。

**試験 e は、上下の領域を手動指定する条件で部分成功。** 同じ青のパレット番号に入る空を動かし、海の検査領域を変更量0にできた。空全体だけを自動で見分けたわけではなく、山や前景の一部も動く。任意の構図に対する「空だけ」の自動分離は未達である。

## 共通条件

先に `docs/adr/0004-color-representation.md` と `experiments/recolor-spike/NOTES.md` を全文読んだ。色変換とk-meansは既存試作からこのフォルダに写した。原寸PNGのブラウザデコード済みsRGBを使い、OKLabに変換する。決定的な32768画素の標本、最遠点の初期化、最大20回のk-means、全画素の最近傍で面積順に並べる条件は同じ。全候補の元の色は共通の8色である。

合成は全候補で次の式だけを使う。

`y_i = x_i + Σ_k w_ik (Q_k - P_k)`

`x_i` は元のOKLab、`P_k` は元のパレット、`Q_k` は編集後。重みは読み込み時に1回計算してFloat32で保持し、a/b/d/eで再計算しない。位置のゲートも同様に固定する。今回は重みの品質の比較なのでCPUで原寸全画素を合成し、sRGB8bitのCanvasに描く。WebGL2の速度・メモリ転送・再生を測った実験ではない。

出力はLと色相を保ち彩度を下げてsRGBに収め、20回の二分探索を使う。ただしLが0〜1を外れると彩度だけでは収められない。該当画素は `lightnessOutPixels` に数える。その場合、診断用画像のsRGB出力は表示範囲へ飽和するため、ADRの色域方針を満たした出力とは扱わない。数値評価はその実際の8bit出力を再度OKLabへ変換して行う。明るさ変更に残る破綻を隠すために、画素を集計から除外してはいない。

## 候補の定義

`d_k = ||x-P_k||`、`n(x)=argmin_k d_k`。同距離なら先の番号を採る。

| 候補 | 読み込み時の計算 | 補間条件・性質 |
|---|---|---|
| 最近傍 `residual` | `w_k=1[k=n(x)]` | パレット点で1。色空間の境で不連続 |
| Gaussian `soft` | `w_k=exp(-d_k²/(2σ²)) / Σ_j exp(-d_j²/(2σ²))` | 非負・連続。パレット点でも他色へ漏れる。σは既存試作と同じ |
| 補間RBF `rbf` | `A_ij=exp(-||P_i-P_j||²/(2σ_r²))`、`v_k(x)=Σ_j φ_j(x)(A⁻¹)_jk`、`w_k=max(0,v_k)/Σ_j max(0,v_j)` | σ_rは全28組のパレット間距離の平均。補間条件を満たし、負値を0にして正規化 |
| 補間Shepard `shepard` | `w_k=d_k⁻⁴/Σ_j d_j⁻⁴`。`d_k=0` はその色を1にする極限で定義 | 非負・総和1・連続でパレット点に正確。近傍のパレットが密だと勾配が強い |
| 空間平滑 `filtered` | Shepardを元画像のOKLabで案内する二方向のbilateralで平滑化し、下記の係数で元の重みに戻す | 補間を保ったまま空間の高周波を抑える追加案。むら・境界のにじみが残る |
| RGBXYの島 `spatial` | 空間平滑の各色を、RGBXYから得る固定ゲートで空側と海側の2色へ分割 | 同じ元色を別の場所で別々に編集できる。手動の領域指定を使う |

Gaussianのσは、各パレット色から最も近い別色への距離を昇順に並べ、番号4の値の0.8倍を0.035〜0.12に収めたもの。

空間平滑の半径は4画素、空間σ=2画素、OKLabの色σ=0.04。横・縦の2回の正規化bilateralを適用する。平滑後を`s_ik`、Shepardを`r_ik`として、`α_i=min(1,min_k ||x_i-P_k||²/0.025²)`、`w_ik=(1-α_i)r_ik+α_i s_ik`。`x_i=P_k` ならα=0になり、その色の重みは1のまま。αを含めて元画像からしか計算しない。近傍は画像端で打ち切り、残った重みを正規化する。

### 論文との関係

[Changら2015](https://pixl.cs.princeton.edu/pubs/chang_2015_ppr/index.php) の原文3.5節はGaussian RBFの連立方程式で補間係数を求め、負の重みを0にして再正規化している。本試作のRBFはこの重みの部分をOKLabに置き換えて実装した。原論文の色域に沿う非線形な単色転送、輝度の単調性制約、12³ LUTは実装しない。したがってChangの完成手法全体の追試ではない。

[Tanら2018](https://cragl.cs.gmu.edu/fastlayers/) の原文3節は5次元RGBXYの凸包・Delaunay分割の重心座標を用いる。本試作はその完全な分解を実装せず、色と位置を併せて固定の層を作るという考えを、**手動seed付きのRGBXY補間ゲート**で検証した代替候補である。Tanの再現精度・速度・自動分離性能を測ったとは言わない。原文も、同色の物体を自動で意味別に分離する保証をしているわけではない。

原文は `~/research/palette-recoloring/sources/chang-2015-palette-recoloring.txt` と `tan-2018-efficient-palette-decomposition.txt` の該当節を読んだ。論文本文と他者のコードをリポジトリへ転載していない。Shepardと平滑化は比較用の追加案で、これらの論文の手法とは区別する。

### RGBXYの島の条件

正規化位置を`u,v`とする。使い手が空側を`v≤0.30`、海側を`v≥0.60`と固定する想定で、ゲートgをそれぞれ1、0とする。境界の中では、上側6点と下側6点の元画像のsRGBと位置をseedに使う。seedの位置は横が0.15/0.50/0.85、上が0.06/0.24、下が0.70/0.94。

各seedへの距離は `D_a=||RGB-RGB_a||²/0.25² + ||(u,v)-(u_a,v_a)||²/0.35²`、補間係数は`1/(D_a²+10⁻²⁰)`。上側ラベル1、下側0の正規化平均をrとする。`t=smoothstep((v-0.30)/0.30)`として、中間帯は `g=1-t+t(1-t)(r-0.5)`。上下の固定値に連続かつ接線が0でつながり、0〜1に収まる。上下の区分は自動推定ではなく、既知の構図に対する指定である。

`w_k,sky=w_k g`、`w_k,sea=w_k(1-g)`、`P_k,sky=P_k,sea=P_k` とする。論理的な操作色は16個になるが、元の異なる色は8色のまま。b/dでは複製した2色を同じQへ動かすため、合算した重みは空間平滑候補と同じ。eだけ空側を動かす。補間条件は複製前の色の合計に対して1であり、同色の2つの島の個別条件は位置も含めて決まる。色だけで両方を同時に1にする矛盾した条件は置かない。

## 試験と指標

- **a / 再現**: `Q=P`。全画素のsRGB8bitのRGBで元画像と比較する。元画像のバイト列をそのまま返す特別扱いはせず、OKLabからの逆変換も通す。
- **b**: 最近傍面積が最大の色（番号0）のOKLCH色相を+120°。LとCは保ち、必要なら目標色のCを下げる。
- **d**: 2番目に大きい色（番号1）だけを明るくする。目標Lは`min(0.98,P_1.L+0.14)`で、a,b成分を保った後、必要なら目標色のCを下げる。他の色は固定。
- **e**: 空と海の検査矩形に共通する青のパレット番号を選び、その色相をbと同じく+120°。色だけの候補はその番号を全体で動かし、spatialだけ空側の複製色を動かす。平らな色面が本試験。他の3枚にも同じ上下指定を適用するが、街路に空と海があるという意味ではなく、位置分離の診断である。

eの空の検査矩形は`u=0.58〜0.95,v=0.02〜0.20`、海は`u=0.62〜0.95,v=0.86〜0.98`。各矩形内の最近傍の数を数え、青の条件`P_k.b<-0.025`を満たす色の中で、`min(空の数,海の数)`が最大の色を選ぶ。該当しなければ青の条件を外して同じ規則を使う。番号は画像ごとにJSONに残す。検査矩形とゲートの固定帯は別の範囲である。

計測配列とは別に、撮影したaのPNG24枚をローカルのPillow 12.3.0で開き直し、元のPNGとのRGB差が全画素0であることも確認した。manifestの撮影96枚の存在と寸法、JPEG12枚の幅1600px以下・合計6MB以下も実ファイルで検査した。Pillowは既存環境での追加確認だけに使い、npmによる再計測の依存には含めない。

以下の`z_i`は、色域処理・8bit出力を通した画像をOKLabへ戻した値、`δ_i=z_i-x_i`、`Δ=Q_k-P_k`、`T_k={i:n(x_i)=k}`、`U_k`はその補集合。最近傍は空間の複製前の8色から決める。xは元のsRGBから計算したOKLabである。

| 指標 | 定義 | 読み方 |
|---|---|---|
| 到達率 | `R=mean_{i∈T_k} ||δ_i||₂ / ||Δ||₂` | 表は百分率。移動の長さの比なので方向までは判定しない。JSONに`mean(δ_i·Δ)/||Δ||²`も保存 |
| 漏れ | `E=mean_{i∈U_k} ||δ_i||₂` | OKLab距離。元の最近傍が別の色の画素への影響。eで海の同じ番号に漏れる現象はこの集合に入らないので、空/海を別に測る |
| 斑点 | `H=sqrt(mean_i ||Laplacian(z)_i-Laplacian(x)_i||₂²)` | 上下左右の4近傍ラプラシアン。外周1画素を除く全画素。元の細部に追加された局所高周波のRMS |
| 再現 | `PSNR=10log10(255²/MSE)`、`MSE=mean(RGB_original-RGB_a)²` | 条件aの全RGBチャンネル。誤差0は∞。b/d/eの変更量に対するPSNRとは区別 |

Hは意図した物体の境界の色替えも数えるので、知覚的な斑点だけを完全には分離しない。また到達が弱い方式はHも小さくなる。そこで比較用に `H/(R||Δ||)` を併記する。これは到達を厳密に揃えて再レンダリングした実験ではなく、変更量を除いた参考比である。8bitの丸め・色域圧縮でRが100%をわずかに超える場合もある。

## 全条件の結果

各行の再現PSNRは同候補・同画像のaから引用する。b/d/eの到達・漏れ・斑点はそれぞれの編集後の画像から測る。漏れと斑点の表の単位は **10⁻³ OKLab**。eのRは同じ番号の空・海・その他を合算した値であり、空だけの到達率ではない。

## 残る問題と次の判断

1. 補間条件はパレット点の条件であり、その最近傍領域全体を目標色に動かす条件ではない。RBFの補間検査に通っても到達が弱い。既定の判断には、使い手が動かしたい画素集合を明確にする必要がある。
2. 単一の色空間の重みだけでは、離れた場所の同色を分けられない。今回は手動の上下指定で検証できたが、固定の領域マスクを使い手が作り直す操作は未実装。山・舟・前景まで含む意味上の島分けは未解決。
3. 空間平滑は細かな粒の指標を減らしても、大きなむらやにじみを生む。半径4pxは原寸固定で、解像度が変わると見え方も変わる。写真と平らな絵の両方に同じ設定を既定にする根拠はない。
4. 明るさの大幅な変更でLが範囲外になる問題は重みだけでは解けない。Qを動かせる上限を画素と重みから検査するか、輝度の変換を別に設計する必要がある。今回のRGB飽和は診断用の表示上の限界として記録し、ADRの色域処理を達成したとは扱わない。
5. 非負・総和1の固定重みなので、色域処理前の各画素の時間ステップはパレットの最大ステップを超えない。ただし今回は時間方向の再生・sRGB8bitのちらつきを測っていない。半精度・重み圧縮・モバイルのメモリも未検証。
6. この4枚は既存の試作と同じ生成画像であり、実写・手描き・本物のドット絵全体への一般化はできない。次はShepardを基礎に、使い手が指定する固定の島と、明るさの上限を先に検証する。
