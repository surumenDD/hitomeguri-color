# README のループに使う絵

README とプロフィールの冒頭のループ（`docs/showcase/hitomeguri-800x500.webp`）の素材。アプリの見本の絵ではない。作り方は `experiments/brand/reel.sh`。

| ファイル | 中身 |
|---|---|
| `festival-girl.png` | 夏祭りの路地と、色鉛筆で描いた女の子。1536×1024 |

- 生成: 2026-10-27、利用者の ChatGPT の画像生成（Claude が Chrome から操作）。
- アプリでは「自分の絵を開く」と同じ扱いで、色の島の役割は自動の推定のまま（手で直していない）。
- 同じ会話の中で、次の順に頼んだ。前の絵の絵柄を引き継いでいる。
  1. 「絵が下手な人が書いた「萌系の小さく可愛い女の子の絵」生成してください」（利用者が考えたプロンプト）
  2. 同じ女の子と絵柄のまま、背景まで描いた横長の絵を3枚（川べりの土手、海辺、丘の上の公園）。
  3. この絵: 「最後にもう1枚、同じ「女の子は色鉛筆の手描きのまま、背景はアニメ映画の美術のように精密で高品質」のギャップで、横長（3:2）をお願いします。時間は夕暮れ。構図は「夏祭りの路地を正面から見る一点透視。両側に提灯と屋台が奥へ並び、空は画面の上に細い帯だけ（藍色から夕焼け）。石畳が少し濡れて提灯を映す。女の子は画面の真ん中の手前、正面を向いて大きめに（膝から上）、りんご飴を持っている」。文字は入れないでください。」
- 女の子と背景を1枚の絵として描いているので、女の子の色も背景と一緒に1日をめぐる。女の子と背景を分けて扱う案は、次の版の候補（利用者の発案、2026-10-27）。
