# 外枠の UI の照合

受け手は、設計と受け入れを担当するメイン。製品の画面にはこの報告を表示しない。

## 対象と方法

指定の `experiments/ui-mock/` の画面写真・template.html と `docs/design/ui.md` を使った。画面写真の固定参照は `test/fixtures/ui/`（2cec53d）、テンプレートと文章は652ee02時点。Product Design の image-to-code / design-qa の照合手順を適用し、ユーザー指定の手元の Chrome で確認した。既存の app・見本画像・操作範囲・終了時の停止を優先し、クラウドへの画像送信や別のプロトタイプは作っていない。

同じ運河・1日の光・3.0秒・未選択で、次の原寸画像を開いて見比べた。

## 確認した点

- 外枠の色、幅、余白、2列と縦積み、絵の縦横比、帯・再生・時刻の配置を照合した。390pxで横にはみ出さない。
- Zen Kaku Gothic New を手元のファイルから読み、見出し・本文・注記・役割名の大きさとウェイトを照合した。Phosphor の再生・一時停止・警告を使っている。
- 製品名、副題、5枚の順番、3つの台本、スライダーの言葉、保存の文を照合した。標準値を中央に置く目盛りは、画面写真後のメインの追記を優先した。
- 帯は平均色で塗らず、指定の2つの島から計算する。現在時刻の地平色が時刻の名前と差し色になる。
- 島は役割の行と面積順の色見本で、すべてを表示する。選択・役割の変更・リセット・線の上下での分割・取消を実際に操作した。
- `reports/M2-ui-island.png`、`M2-ui-split.png`、`M2-ui-export-progress.png`、`M2-ui-error.png` も開いて、メインの追記した面・余白・文字・線・明るさ35%・進み具合・中止の場所を確認した。
- 帯と分割線の矢印キー・Shift・aria-valuetext、ボタンの選択状態、書き出し開始時の中止への焦点、無効な操作、PNGの保存、動画の中止をChromeの操作テストで確認した。reduced motionでは5秒待っても絵と時刻が変わらず、手動移動は使える。
- 読み込み失敗では前の絵を残し、画像の下に具体的な文を出す。ブラウザ例外と外部へのリクエストは0。

役割名の文章12/16pxと旧テンプレート20pxの食い違いはメインに確認し、12/16pxと上の余白2pxで揃えた。

P0・P1・P2の未解決事項はない。絵そのものの細部はモックの縮小済み画像より鮮明で、帯の色は現在の v4.1 に従う。これらを外枠の色や間隔で補正していない。追加の視覚判断はメインのレビューに委ねる。
