## 安全の数値と検査条件

端点行列の各MP4は384×256・30fps。node版には `--css-px-per-px 4` を渡し、1536px幅相当の視野で判定した。全条件・各判定・Lの丸めの数値は [M2-engine-metrics.json](M2-engine-metrics.json)。動画と完全な判定ログは `test/results/m2-v41-videos/` にある。旧v4でも120本を検査した後、メインのv4.1変更を受けて出力先を分け、120本を作り直した。

L の丸めは、元の1536×1024画素・固定重みで、描画をせずに60fpsの式を精査した値。各フレームで最大となる画素数を報告する。上限はメインがADR-0004に追記した「画素の0.5%以内、Lの逸脱0.08以内」。

| 見本     | 丸めた画素の最大数 | L の逸脱の最大 |
| -------- | -----------------: | -------------: |
| 運河の街 |              5,449 |      0.0621034 |
| 雪の村   |                 27 |      0.0351534 |
| 灯台の岬 |              5,078 |      0.0347465 |
| オアシス |              1,878 |      0.0307754 |
| 港町     |              5,199 |      0.0527018 |

最大5,449画素は0.346438%で予算内。候補を作る段階のLの包絡だけで断らず、候補画素を元の式で精査する。通常の描画でのLの丸めは最後の砦として残した。GPUの浮動小数点と式の1e-7の許容差による境界差を区別するため、オアシスと分割した港では8時点の実シェーダの診断画素数も [M2-islands.json](M2-islands.json) に記録した。

見積もりはパレットの動きと非負・総和1の重みを使い、画像を描かない。パレット色の点滅は各色が視野全体を占める条件で判定する。Lの精査と見積もりはWorkerで動く。最後に書き出す動画の縮小した全フレームを実際に描き、移植した解析のWCAG・ITUの両方が通らない動画は保存しない。端点行列の結果は指定された見本・係数範囲の検査結果であり、任意の画像に対する事前の証明とは扱っていない。

## 位置の島・描画・書き出し

[オアシスの8時点](M2-oasis-eight-times.jpg) では、矩形に入る3色を別の島として灯りにした。夜のテントは琥珀に灯り、砂丘と岸にテントの灯りの重みは乗らない（矩形外の重み0）。[港町の8時点](M2-flat-eight-times.jpg) は共有色を上から50%の線で分け、上を空・下を水にした。ぼかしは3px、全島の重みの総和の誤差は約6e-8以内。元のパレットの値を複製してから重みを二分するため、残差を保つ合成式を変えていない。

動画は各フレームの時刻を `i/30` として作り、実時間の再生やMediaRecorderに依存しない。端末のH.264対応を調べ、フレーム・エンコーダー・GPUを後始末し、中止も扱う。MP4に島の選択・分割プレビューを入れない。PNGもその時刻の実際の絵を保存する。

1080p のファイルは `test/results/m2-v41-videos/1080p-12s.mp4`（16,937,323 bytes）。3:2の絵を16:9に収めた検査用で、通常の保存は元の縦横比を保って長辺1920以下・偶数にする。元サイズのnode検査は [M2-full-flash.json](M2-full-flash.json)。継ぎ目は復号RGBを384×216に縮めてMAEで測り、0.4467/255。通常の隣接フレームの中央値0.4040、95%点1.0120、最大1.3435と同程度の範囲だった。直近の最初の隣接差は0.1104、最後は0.0482で、圧縮された先頭フレームとの誤差は残る。[M2-loop.json](M2-loop.json) に全数値と判定条件を記録した。

## dsh の Task と体制

[Task分割](../tasks/M2-plan.md) と各仕様にAPI・入力・正本・許容差・持ち場を固定した。起動は指定のdsh-launch.sh、同じRun。両方のworker_doneを受け、原文とコードを一次レビューして再検査した後に結合した。

| Task                                          | モデル                       | 起動→完了（UTC）  | 所要    | 手戻り                                                         |
| --------------------------------------------- | ---------------------------- | ----------------- | ------- | -------------------------------------------------------------- |
| [点滅解析の純粋な移植](../tasks/M2-flash.txt) | deepseek/deepseek-v4.1-flash | 18:46:37→18:51:06 | 4分29秒 | アルゴリズムの修正なし。15条件・全フィールド一致を親でも再実行 |
| [2段の帯のデータ](../tasks/M2-strip.txt)      | xiaomi/mimo-v2.6-pro         | 18:47:25→18:55:47 | 8分22秒 | 仕様の修正なし。11条件を親でも再実行                           |

今回は遅い大きなTaskにせず、正本のある純粋関数だけを渡したため、親の結合実装と並べられた。単に「移植して」より、型・選び方・同点・丸め・固定入力・完全一致を先に決めた契約が効いた。台本の改訂、安全の許容、UIの追加状態など設計が動く部分は親が持ち、メインに質問する形がよかった。入れ子の起動失敗はなし。両ワーカーの端末資源は解放済み。
